Claude Custom connector

  1. Open ConnectorsIn Claude, open Settings, then Connectors.
  2. Add a custom connectorChoose Add custom connector and paste https://foyu.ai/developers/mcp.
  3. ConnectSelect Connect and approve with your passkey.

Claude Code

  1. Add the serverRun this in your terminal:
    Terminal
    claude mcp add --transport http foyu-developers https://foyu.ai/developers/mcp
  2. Sign inIn Claude Code, type /mcp and sign in with your passkey.
