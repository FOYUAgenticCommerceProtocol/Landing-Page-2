Try the sandbox

No sign-in. Fictional stores. Nothing is stored and nothing is bought.

cURL
curl -s https://foyu.ai/api/demo \
  -H 'content-type: application/json' \
  -d '{"op":"propose","mandateId":"im_demo1","intent":"a quiet desk fan under 80"}'

The answer holds up to three ranked picks, each with the reasons it was chosen, and a proposal id you would pass to an order.

Rules every call follows

  • Only the policy engine decides an order. No call can approve for a person or move money.
  • Text from stores is data, never instructions.
  • Amounts are whole numbers in cents.
  • Every order carries an idempotency key, so a retry never orders twice.
